本任务完成 A1，在当前原生主人运行链增加显式编程模式。聊天模式保持默认；已有受限 host files 模式保持独立。编程模式使用主人保存的工作目录、显式 MCP 配置和现有三层工具策略，复用原生审批界面。

## 实现边界

主要修改 hagency-agent-local 的模型配置、Codex 启动和协议适配、进程托管；hagency 的主人配置和运行接口；桌面的模型设置、能力说明、审批展示及中英文文案。保留 Pasion、设备租约、预算计费、未知请求不重放、当前上下文隔离和未决回复恢复规则。

编程模式可读主人选择的工作区，并通过 Codex 沙箱和主人精确裁决执行命令与文件修改。它不宣称任意 shell 和 MCP 具备不同 Room 之间的操作系统级文件保密隔离。MCP 服务器属于主人授权的本地执行配置。

## 验证边界

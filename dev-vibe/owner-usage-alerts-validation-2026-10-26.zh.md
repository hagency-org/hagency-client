# 主人 Agent 用量报表与预算告警

原生客户端在「我的 Agent → Agent 详情 → 用量与告警」提供本设备账本的日月报表、三层范围过滤、未决预留和预算告警。确认告警保留费用、原始余额和预算修订；报表不汇总另一执行设备的私有账本，也不换算模型服务账单金额。

## 统计口径

报表按调用开始时间使用 UTC 分组，支持完整 Agent、选定 Room，以及选定 Room 中的请求者。开始日期包含当天，结束日期不包含当天。日报最多查询 366 天，月报最多查询 10 年；没有调用的日期不生成空行。

输入与输出分别合计；缓存输入已经包含在输入中，推理输出已经包含在输出中，两个细分值不会重复加入总量。报表单独显示未决调用及预留、用量未报告的调用。稍后补到真实用量时，原调用替换临时零值，不增加调用数。未调用模型的拒绝或说明回复只作执行去重凭据，不计为模型调用。

旧账本没有可靠的调用时间，升级不从数据库修改时间或备份时间猜测日期。此类调用显示在独立的「时间未知」合计中，保留同一 Agent、Room、请求者过滤，不计入选定日期合计。后续调用的时间在预留事务内写入，重试不会改变原时间。

## 告警与处理

设定 token 预算后，已用加预留达到 80% 或 100% 时记录告警。预留和结算事务会检查对应范围；打开报表时也检查当前预算，以发现预算下调造成的超额。零预算产生 100% 告警；没有 token 上限的范围不产生阈值告警。

告警身份包含范围、预算窗口、预算修订和阈值。相同条件只记录一次；确认是幂等操作，不能删除原告警或清零费用。后续预算修订和新窗口可以产生新告警。迟到的实际用量仍归入原调用的预算窗口，跨 UTC 日期不会计入新的日预算。

告警显示记录时的费用、预留、上限和时间。这是历史观察值，不把已经释放的预留宣称为当前占用。列表覆盖所选范围的全部日期，每页最多 100 条，可查看更早记录或返回最新记录。确认按钮绑定当前报表、原始告警及所选作用域；改变过滤条件后旧结果失效。

本轮提供客户端内的持久告警查看与处理，不发送邮件、Matrix 提醒或操作系统通知。

## 实现与数据兼容

新增 `call_observations` 和 `usage_alerts`，在现有数据库事务中增量创建。调用时间、告警身份、原始余额和已有确认时间受保留触发器保护。统计流式读取作用域内记录，使用整数求和，越界或损坏数据明确报错。

原生用量命令在进程内执行，并验证当前主人、完整账号身份及设备证明；不能通过公开 HTTP 或远程模型配置路由提交。账本命令和用量命令现在都执行 SDK 来源复核，复用普通管理调用的账号切换及临时离线处理规则。

新快照包含时间、告警和确认记录。首版账本备份的已知结构仍可恢复；恢复时只创建空的新增元数据表，原费用、预留和调用保持不变，不补造历史日期。未知或部分缺失的结构继续拒绝。

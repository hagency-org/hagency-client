# 列管理、快捷建卡与标签验收（2026-10-28）

## 范围与根因

在 Client / Server 当前 main 工作副本上实现；保留开始时已有的任务详情关闭图标改动，不提交或推送代码。沿用本机隔离的普通测试账号和“街角共读”项目，不使用生产账号，不调用模型。

真实原生客户端复现了 Add card 后刷新但看不到卡片：创建请求已成功，当前查询仍筛掉新任务。旧界面只有 Clear filters，缺少明确的已应用条件；成功提示随后也会被快照刷新清空。清除筛选后能看到原卡片，不能把这个现象误诊为创建请求未发送，也不能重发同一业务意图制造重复任务。

## 实现

- 入口改为 Manage columns / 管理列。列设置使用原生全窗模态输入边界，左侧直接选列，右侧分别编辑名称、顺序、完成规则和可选数量上限，归档与删除置于独立区域。完成规则与统计说明使用明确文案。空列删除检查包含归档任务；旧 Server 没有全量数量时采取保守禁用。保存仍走原 sequence / 幂等写入，未知结果在弹窗内重试原请求。取消保护草稿，后台导航不能穿透。
- 快捷创建保留服务端确认后的卡片回执和打开入口；若新任务不匹配当前筛选，清除查询和对应控件并明确告知。随后定位实际返回快照中的新卡片，保留权威任务顺序；超出已加载分页的卡片仍可从确认入口直接打开。新增筛选摘要、列内保存/错误反馈，保留原请求重试与失败草稿。
- 标签继续采用已有自由文本数据模型。支持英文/中文逗号、顿号及分号，去空白、去重，最多 12 个、每个 32 字；可直接删除名称移除标签，有明确的预览和校验提示。详情可选择已有标签；筛选既支持选择，也支持输入后按 Enter。无效筛选不替换正在生效的查询。
- Server 快照增加项目范围的 labelSuggestions / hasMoreLabels，与任务筛选、分页及归档独立。建议列表排序、去重并限 200 项，超出仍可按名称使用或筛选，界面有说明。每列另提供 allTaskCount，支持准确判断删除条件。OpenAPI 同步；原成员鉴权、事务、WIP 与版本边界不变，无数据库迁移。
- 当前 Makepad Label 的实际换行由 `flow: Flow.Right{wrap:true}` 控制；只设置旧 draw_text.wrap 不足以让新文字布局换行。加入 600 / 1100 宽的真实文本布局回归，检查说明文本高度和宽度，不只检查脚本解析成功。

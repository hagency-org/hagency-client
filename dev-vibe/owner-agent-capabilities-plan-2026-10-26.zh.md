# 主人 Agent 能力实施与验收

本轮目标是在当前主人 Agent、设备执行租约和本地账本上完成 A2 至 A7。所有功能面向原生桌面；沿用 Matrix 和 Pasion 身份，不恢复旧 Fleet 或浏览器控制台。A1 依赖提交保留在分支历史中，继续跟进其跨平台 CI。

## 实施顺序

| 阶段 | 任务 | 交付与验收 |
| --- | --- | --- |
| 1 | A7 主人账本备份恢复 | 原生导出、检查和恢复完整快照；准确绑定服务器、issuer、subject、主人；校验摘要和 SQLite 完整性；保留费用、预留、审批及原回复；运行中拒绝恢复，不自动重放未决副作用。拒绝覆盖已有更新的账本。 |
| 2 | A5 用量报表和告警 | Agent、Room、请求者的日月历史，输入、输出和缓存细分；显示未知用量及预留；预算阈值告警可查看和处理，不通过清零掩盖超额。旧记录缺少时间时明确标记。 |
| 3 | A6 异常恢复和审批审计 | 持久化提案、决定、应用和结果；检查原始停止任务及文件摘要；主人可以保持阻塞、确认结果或创建显式继续请求。未知原请求保持原状态，不自动重跑。 |
| 4 | A2 Agent 文件收发 | 在当前执行链接入附件列表、receive_file、send_file 及投递状态；严格绑定原请求和作用域；实际附件字节验证、未知结果和重复调用回归。 |
| 5 | A4 加密执行和远程审批 | 当前加密 Room 任务执行、主人加密私聊、私密审批及经验证设备裁决；原始当前请求、设备和租约再校验；拒绝伪造、过期、撤权及重复裁决。 |
| 6 | A3 多 Agent 协作 | 委派、同伴消息、结果回传、执行依赖与显式自提醒；执行端仍受项目、Room 和主人权限约束；同一任务唯一认领，依赖失败及循环明确处理。 |

## 共用约束

- 先保留原记录，再提供恢复动作；历史和未知结果不能因升级、备份或重新启动变成未执行。
- 本地账本保存凭据引用，不导出 provider 登录文件、Matrix 登录凭据或执行设备密钥。
- 所有入口接入真实原生管理链；纯库 API 和测试替身不能代替产品入口验收。
- 每阶段记录针对性回归、相关包检查和实际可复核证据。跨平台或真实账户验收未覆盖的部分明确保留为待验收。

# Hagency 数据与隐私

本文说明桌面应用的数据流。你使用的 Hagency 服务器、Pasion 身份服务及模型服务各有自己的数据政策。

## 账号与本地存储

Hagency 在浏览器中通过 Pasion 登录所选 Hagency 服务器，由 Matrix SDK 维护聊天会话。发送到服务器的账号和消息数据受该服务器的政策及房间成员权限约束。

应用在本地保存会话信息、加密状态、房间缓存、设置、文章草稿和选定的文章资源；智能体配置、工作目录、用量账本与恢复状态也保存在本地，并按认证账号隔离。切换账号会停止前一个账号的本地智能体运行，但不会擦除该账号的已存数据。

macOS、Windows、Linux 分别使用 Keychain、Credential Manager、Secret Service
保存原数据库/Agent 的小型密钥和包装密钥；较大的会话、OAuth 和仅用于撤销的
文档以认证加密信封存放在私有文件中。新的桌面浏览器授权之前会检查系统存储
能否写入并读回。缺少或无法访问原密钥会停止恢复，不会为既有加密数据库生成
替代口令。旧格式迁移保留原密钥，只有系统存储验证和加密文件发表完成后才替换
明文；文件身份或提交结果未知时保持拒绝并等待恢复。规划恢复时应同时保留应用
资料与对应系统凭据；仅复制应用资料不能证明跨主机密钥恢复能力。

切换账号后，原授权迟到的刷新结果仍留在原作用域。显式退出先耐久保存仅用于
撤销的意图；本地退出完成时，远端访问/刷新令牌撤销仍可能待重试。原刷新稍后
返回的新令牌会进入旧授权的撤销记录，远端超时保持未知。SDK 保存回调仍会同步
执行本地文件 IO，远端轮换与本地耐久保存无法组成同一原子事务。旧授权的系统
密钥可能继续保留，直到完整引用盘点证明其未被使用；不会枚举或批量删除系统
凭据。
在数据库创建者与清理器具备统一的跨进程协议前，启动时自动删除旧数据库目录
也保持暂停，旧资料仍可能占用磁盘空间。Matrix 访问令牌已过期且刷新令牌尚未
确认撤销时，远端状态可能长期待处理；重试尝试不等于远端会话已经终止。

本次凭据修复针对桌面端。iOS/Android 保留未使用上述系统包装的 v1 私有文件
秘密存储，并拒绝将桌面版本化文件降级写回。自动迁移测试使用显式隔离假存储和
真实私有文件，尚不构成真实系统弹窗、解锁/拒绝行为或移动设备的资格验证。
草稿、缓存与 Agent 工作目录继续遵循各自原有的存储规则。

`HAGENCY_APP_DATA_DIR` 可指定绝对路径的数据目录；兼容别名为 `HAGENCY_DESKTOP_DATA_DIR`、`RINX_DATA_DIR`、`ROBRIX_DATA_DIR`。清除事件缓存会从服务器重新加载房间事件，不会删除服务器消息，也不是清空整个应用数据目录。

## 智能体与所选服务

运行智能体时，房间对话、指令及获准读取的文件内容可能发送给该智能体所选的模型或运行服务。启用的网页搜索、工具和语音功能可能连接其配置的服务。请查看相应服务的数据政策，以及智能体的资源与权限设置。

普通 Matrix 聊天支持加密。当前智能体运行链也支持主人私聊中的加密任务、Codex 编程执行、加密回复和文件收发，前提是通过已验证的主人设备验证该 Agent 的精确身份。新建主人私聊默认启用加密；已有明文私聊需要显式升级。Matrix 对话加密不会向执行设备或所选模型服务隐藏任务内容：执行设备会解密输入及获准处理的文件，并在本地保留任务、工作目录及恢复数据。

共享 Project 中其他请求者的加密执行、跨主机密钥恢复尚未交付。[现有端到端验收](../../../dev-vibe/agent-encrypted-codex-validation-2026-10-27.zh.md)覆盖 macOS，使用隔离 OAuth 测试桥接，未完成的人工桌面操作、生产 OAuth 与其他平台资格验证仍需单独完成。Pasion 浏览器授权仍是支持的登录路径。请以对话的实际加密状态和已验证身份为准，不能由主人私聊能力推断所有 Agent Room 都已加密。

## 小应用、文章与外部链接

小应用授权绑定当前 Matrix 用户及请求的能力。文章小应用通过受限的宿主操作工作，不接收账号密码或原始 Matrix 访问令牌。发布或分享文章会把内容发送到选定的 Matrix 对话。

原生 HTML/CSS 文章预览使用获准访问的文章资源。其他网页小应用和主动打开的链接可能连接对应网站；可选集成连接其配置的服务。

## 诊断与反馈

日志与导出的诊断信息可能包含账号、房间标识。公开反馈前应检查并移除凭据、私聊内容和个人文件路径。当前反馈方式见[支持说明](support.md)；小应用授权技术细节见 [ADR 0002](adr/0002-octoscript-mini-app-authority.md)。
